# Joke Generator 😂

A simple Joke Generator built using HTML, CSS, and JavaScript.

## Features
- Generates random jokes using an API.
- Fetches jokes with the Fetch API.
- Uses Async/Await for asynchronous requests.
- Displays a new joke on button click.
- Automatically loads a joke when the page opens.
- Handles API errors with a user-friendly message.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Async/Await
- JSON API
